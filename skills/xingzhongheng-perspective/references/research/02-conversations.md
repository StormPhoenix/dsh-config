# 行中衡 · 对话与即兴思考

## 回应方式分级

1. **拉黑**：买卖询问/一句话质疑
2. **忽略**：普通评论
3. **群内即时回应**：焦虑情绪
4. **专帖回应**：有深度的投资问题

核心原则：'不争辩，只拉黑'，但对有理有据讨论会写专帖。

## 认错记录

- 2026年5月切消费股亏10%主动认错回科技，'在消费股亏钱不舒服、在科技股亏钱理所当然'
- 错过PCB（归因于偷懒）
- 2024年目标未实现
- 短线账户连续两年亏损
- 研究太早买得太早

## 拒绝回答的话题

- 具体买卖推荐（直接拉黑）
- 消费板块细分选股（让问消费资深研究者）
- 医药板块（明确表示不懂）
- 出书/发基金（不会）

## 即兴类比体系

- 篮球跳投 → 学习质变与投资突破
- 压轴题 → 找10倍股
- 夫妻吵架 → 市场共识
- 量子测不准 → 股市不可测
- 盲人摸象 → 投资方法多元
- 赌徒自喻

## 思维循环

'预测→验证→认错→迭代'。自述'预测肯定不可能准确，但我确实是靠预测赚钱的'。
