本技能提供指令和本地资料，不注册新工具。仅调用当前会话实际提供的工具；若工具通过 `run_code` 暴露，在其中调用 `tools.<工具名>`，不要直接调用未声明的工具。

技能内的参考资料路径相对宿主提供的技能资源根目录（`Base directory for this skill`）解析；用户文件、调研结果和代码输出路径相对当前工作区或用户确认的输出目录解析，不写入技能资源目录。只按需读取资料。

读取文本使用 `read({file_path, offset, limit})`，搜索内容使用 `grep({pattern, path})`，发现文件使用 `glob({pattern, path})`；`glob` 不列目录，目录存在性或目录列表使用 `bash`。修改现有文件前先 `read`，精确修改使用 `edit({file_path, old_string, new_string})`，创建文件使用 `write({file_path, content})`。不得覆盖未经确认的已有输出；写入后重新读取验证。

Step 2 的"派活"使用当前可用的 `subagent`：类型 A 答题、类型 B 验证各自独立派发，同时最多 3 个，先收集全部必需结果再进入 Step 3；不隐式创建 Agent Teams，子 agent 不再派子 agent。检索使用 `web_search({queries: [查询]})`（每次 1–4 个查询），全文阅读使用 `web_fetch({url})`。JavaScript 动态页面或登录页面使用当前已连接的 Playwriter 工具，先观察、再操作、再观察；不接管用户未指定的已有标签页，不绕过访问限制。网络不足时标记信息缺口，不编造来源或数据。

`scripts/repay_period.py` 以 bash 运行，路径拼技能资源根目录（如 `python3 <技能根>/scripts/repay_period.py ...`），只读计算、不写文件。最终单文件 HTML 报告写到用户工作区或用户确认的输出目录，并在回复中告知路径；保留分叉三"资金驱动、非价值支撑"标注与免责声明，不构成投资建议。

# 迭代分析树（A 股个股深度研究）

对研究问题反复执行「MECE 切开 → 排优先级 → 纵向挖掘」，让树逐层生长，最终逐块回答：① 当前合理价值 ② 未来价值 ③ 炒作价值。**共享内核只跑一次，三个分叉按运行模式裁剪**。共有 10 个 Step，按顺序并根据以下指引执行：
1. 定方向、选运行模式、落位三分叉
2. 派活研究（共享内核）
3. 逐层拆树（切 → 排 → 挖）
4. 数据核验与勾稽
5. 过五道审查闸门
6. 分叉一：当前合理价值
7. 分叉二：未来价值
8. 分叉三：炒作价值
9. 现实审查
10. 输出与交付

## 运行模式（Step 1 选定，默认全量）

| 模式 | 跑哪些分叉 | 适用 |
|---|---|---|
| **快速** | 只分叉一 | 只判断"当前贵不贵" |
| **标准** | 分叉一 + 分叉二 | 基本面完整判断（两者互校） |
| **全量**（默认） | 分叉一 + 二 + 三 | 产出完整三分叉报告 |

- **依赖铁律**：分叉二**必须**在分叉一完成后跑（用其常态中枢做 ±20% 校验）；分叉三独立，任意时点可跑。
- **按需加载**：快速模式只需读 `references/forks.md` 的「分叉一」小节，不必载入分叉二 / 三。

## 必须遵循的重要原则

- **一切归于利润与供需** → 表达贵贱只写回本年限与年化收益；正文、KPI、结论中不得出现 PE、PB、市盈率、市净率（P1）
- **门槛回报统一 9.6%** → 回本年限法全文只用一个门槛 R = 9.6%（推导口径：无风险利率 + 风险溢价）；不得出现 10%、12% 等其他值（`valuation.md` 第 6 条）
- **共享内核只跑一次** → 三个分叉共用同一批数据与同一套审查；**不得各自重新检索**同一批数据（本 skill 模块化的前提）
- **每切一刀就排一次优先级** → 深度优先给影响力最高的那一支，不是平均用力列清单（P2）
- **每个推算值都必须能溯源** → 能溯源的是数据，不能溯源的是幻想；答不出出处的一律删掉或显式降级为情景假设（P9）
- **主 agent 只做拆树与判断，检索与作答交给子 agent** → 子 agent 产出须过「交叉验证 + 五道闸门 + 现实审查」，循环至通过才采信（S0）
- **结论必须通过行为主体检验** → 扩产要赚钱、退出要亏钱（P8）
- **用不可逆因素定中枢、可逆因素定波动** → 趋势看变化率，供给要算时滞（P3）
- **先取证、后结论** → 禁止先定目标价再凑支撑（G5）
- **一次只做一类事** → 检索阶段不下结论；分析阶段不临时补检索（需补则重新派活）

## 工作流程

### Step 1：定方向、选运行模式、落位三分叉

- 立两个方向：**一切数据归于利润、一切因子归于供需**。这两个方向同时是剪枝标准。详见 `references/principles.md`（P1）。
- **选定运行模式**（快速 / 标准 / 全量，默认全量）；据此决定后面跑哪些分叉模块。
- **初始问题就是三分叉**，**直接落位、不推导**：① 当前状态下的合理价值；② 预期未来的合理价值；③ 是否存在炒作价值。
- MECE 从这三块的**下一层**才开始用。

### Step 2：派活研究（共享内核）

主 agent 定命题、派活、审查；**检索与作答交给子 agent**。模板与判定规则见 `references/delegation.md`。

- **类型 A（答题）**：接收一个命题 → 自己检索一手资料 → 产出 md 研究报告，逐条列全支撑信息（值 + 时点 + 来源 + 口径 + 等级）。
- **类型 B（验证）**：另找来源，**不复用 A 的来源**，逐条独立核验 A 报告的每条信息。
- **三道审查环，缺一不可**：
  1. **交叉验证**（B）：信息真不真；
  2. **五道闸门**（G1–G5，见 `references/audit-gates.md`）：推导成不成立；
  3. **现实审查**（主 agent）：结论站不站得住（P5 三问 + P8 行为主体检验）。
- 任一环不通过 → **写明理由退回原 A 修改**，循环至通过；**通过前该命题结论不得进入报告**。
- 硬规则：只有主 agent 能派活（子 agent 不能再派子 agent）；**先派活、再动手**；同层可并行，**同时最多 3 个子 agent**，且 B 不得与 A 相同。
- **内核产物一次性产出**：三个分叉所需的成本梯队、产能、售价、报表对账等基础数据，在此统一取齐，供 Step 6–8 复用。

### Step 3：逐层拆树（切 → 排 → 挖）

每层重复同一序列，机制与案例见 `references/workflow.md`。

- **① 切**：选一个维度，把节点切成互斥穷尽的组成部分；同层只用一个维度。
- **② 排**：对刚切出的并列子节点按**影响力**排序（谁变一档，父命题动得最多）。
- **③ 挖**：**只对影响力最高的那一支**纵向追问"由什么决定""现在处在什么状态"；其余降为参数。
- **铁律**：每做一次 MECE 切开，就立刻排一次优先级。
- 每层切完做**回溯验证**：子命题全真 ⟺ 父命题真；否则换维度重切。
- 两个锚：原因类节点归**供需**、结果类节点连回**利润**；取数撞异常值 → 立刻优先深化那一支。
- 节点必须是命题，记录四项：`命题 | 数据（值+时点+来源）| 当前判断 | 状态`。

### Step 4：数据核验与勾稽

- 每个数据进入测算前过三问：**口径 / 时点 / 机制**；取数顺序：**公司披露 > 官方统计 > 第三方汇编**（P5）。
- **反算核验**：参数 × 总量 必须等于已知总量；差距大就先查口径 / 时点 / 定义（P7）。
- **勾稽**：用恒等关系倒推缺失值、核验存疑值；倒推值标"自算估计"（P7）。
- **趋势差**：对每条线算趋势，用"供给侧趋势 − 需求侧趋势"推结论；优先用**绝对量**，慎用百分比 / 比率。详见 `references/principles.md`（P7）。

### Step 5：过五道审查闸门

结论必须逐条过 G1–G5，细则见 `references/audit-gates.md`：

- **G1 报表对账关**：结论里每个数必须落到报表某一行（附「结论数 → 报表行」对照表）。
- **G2 禁止残差反算**：校验输入必须独立于被校验对象。
- **G3 薄毛利规则**：`(售价−完全成本)÷售价 < 15%` 时取消"次要变量"档，每个损益行项都必须落到报表行。
- **G4 对称验证**：每个乐观输入都要用"已发生的、可核实的事实"证明可达；公司目标须按历史兑现率打折。
- **G5 禁结论先行**：先逐条核实输入，再由输入生长出结论；输入查不到当场作废。

### Step 6：分叉一 —— 当前合理价值

模块细则见 `references/forks.md`「分叉一」。

- **动态视角**（P3）：用不可逆因素（成本结构）定中枢，可逆因素（价格波动）定波动。
- **中枢可行性检验**（P4 五步）：成本梯队两种中位数 → 亏损面曲线 → 现金成本线 → 历史耐受时长 → **产出形态检验**。让"半数以上主体长期亏损"的是**洗牌价**，不是中枢。
- **常态利润** =（公司实际售价 − 常态成本）× 量；**合理价** = 常态利润 × 回本年限 ÷ 股本。
- 口径钉死见 `references/valuation.md` 第 1 / 3 / 4 条；算法见 `references/methods.md`，脚本 `scripts/repay_period.py`。
- **校验**：常态口径必须能反算回最近一个**微利年**的实际归母，误差 >10% 即口径错配。

### Step 7：分叉二 —— 未来价值

模块细则见 `references/forks.md`「分叉二」。**必须在 Step 6 完成后执行**（以其常态中枢为基准）。

- **周期链条推演**（P6，不许跳步）：产能收缩 → 传导（时间 + 数量）→ 价格路径（冲高 → 高位 → 回落，反转是**超调**）→ 逐年利润路径 → 路径求和。
- 拆供需两条 MECE 腿：**供给 = 数量 × 效率**；**需求 = 基数 × 强度**；价格 ← 供给增速 − 需求增速。
- 用**四条水平线并排法**（源头产能 / 实际供给 / 需求 / 价格，均为水平值而非增速）；效率序列须分解"一次性修复 / 可持续提升 / 结构置换"，只有后两类可外推。
- **路径求和法（高位年口径）**：合理价 = 高位年平均利润 × 回本年限 ÷ 股本；同时给出**含反转年的保守下界**（`valuation.md` 第 5 条）。
- **强制校验**：比分叉二与分叉一，**相差在 ±20% 以内即触发「分叉二沦为分叉一复读」告警**，改用路径求和法或回查链条。

### Step 8：分叉三 —— 炒作价值

模块细则见 `references/forks.md`「分叉三」。**独立模块**，仅在全量模式下执行。

- 分析题材与事件驱动、资金面（融资 / 北向 / 主力）、筹码结构（股东户数 / 解禁 / 成本分布）、情绪与拥挤度。
- 输出炒作价值区间、触发条件、证伪条件。
- **纪律**：结论**必须标注"资金驱动、非价值支撑"**，**不得进入分叉一 / 二的基本面测算链条**；不得用 PE / PB 表达高低；不构成投资建议。

### Step 9：现实审查

- 交付前把结论反过来审：**这个结论要求某主体做出"违反其自身利益"的行为吗？** 是 → 反现实，无论算式多漂亮（P8）。
- 把每个主体行为单独拎出来，写出"**他为什么会这么做**"；写不出 → 结论不成立。
- 核心判据：**扩产要赚钱、退出要亏钱**；再查成本 / 资金 / 时滞 / 能力四重约束。
- 报告须有独立一节「现实审查」，逐条列出：主体行为 → 动机 → 在本结论的水平下是否成立；不成立的行为从结论里删掉并修正结论。

### Step 10：输出与交付

- 交付**单文件 HTML**（双击可开、可直接分享），完整规范见 `references/output-html.md`；树的命题骨架与结构示例见 `references/example-tree.md`。
- **按运行模式裁剪章节**：快速模式只出分叉一；标准模式出分叉一 + 二；全量模式出三分叉。
- 必备板块：首屏结论先行（一句话本质 + 所选分叉的结论卡）；树画成 SVG（非文字缩进）；数据核验表；**推算值溯源表**（每个推算值写清依据 + 时点）；免责声明。
- 交付前自检：内联 JS 可被解析、标签配对无缺（漏一个图表容器就整块空白）；**逐个数核对——每个推算值都能当场答出出处（P9）**。
- 输出前对照 `references/pitfalls.md` 的陷阱表检查一遍。
- 告知输出路径。
