# 陷阱速查

每次输出前对照检查一遍。这是实践中反复出现的失焦方式。

| 陷阱 | 表现 | 对策 | 详见 |
|---|---|---|---|
| **平均用力** | 把 MECE 拆出的并列节点平摊深度，不排序；或把低权重项（政策、资金面、估值比率）写成重点 | **每切一刀就排一次优先级**，深度优先给影响力最高的一支 | workflow.md S3 |
| **中间比率** | 用 PE、PB、ROE 等衍生比率代替利润本身来论证贵贱 | 只写回本年限与年化收益 | principles.md P1 |
| **外部预测** | 把卖方或市场一致预期当作自己的输入或结论 | 一切预测自算；外部数据只用于判断"价格已定价什么" | valuation.md |
| **静态中枢** | 把驱动变量的中枢当成常数，忽略不可逆因素使它逐年漂移；或用可逆的周期高点当持久中枢 | 用不可逆因素定中枢、可逆因素定波动；看变化率而非静态值；给供应加时滞管道 | principles.md P3 |
| **中枢不可行** | 推出的中枢低于行业大量主体的成本——那些主体必然退出、价格必然被推回，所以该中枢在现实中站不住 | 做亏损面 / 现金成本线 / 历史耐受时长三项检验 | principles.md P4 |
| **洗牌价当中枢** | 把周期底部（出清尚未完成时）的实际成交价当成长期中枢；用"成本平均＋微利"当合理价，等于默认半数生产者长期亏损 | 检验**产出形态**：合理中枢应让"大多数主体微利、少部分亏损"；半数以上长期亏损的价格是"洗牌价" | principles.md P4 |
| **保本线当中枢** | 用"行业平均完全成本"（保本线）当中枢——等于假设半数主体长期不赚钱，与"洗牌价当中枢"同源，系统性低估 | 中枢取**实证的"行业整体微利"时段的价格**；找不到微利锚时用"保本线 + 有依据的微利溢价"，并过产出形态检验 | valuation.md 第 3 条 |
| **口径双重扣减** | 中枢按"含下游溢价的零售 / 集贸口径"定，又对公司价再扣一次"零售 vs 出厂"的口径差——同一口径差被扣了两遍，凭空再造一次假价差 | **中枢与成本必须同源**；口径差**只扣一次**；公司价用恒等关系自算并与同口径行业价对照 | valuation.md 第 1 条 |
| **冻结最新成本** | 常态成本直接取"最近一期实际值"，等于假设降本趋势立刻停止，与 P3（趋势有惯性）矛盾 | 常态成本 = **最近实际值 − 已确认的可持续降本幅度**，下限 = 现金成本 | valuation.md 第 4 条 |
| **目标当依据** | 把公司降本目标 / 管理层指引直接当常态成本依据，未兑现的目标一路畅通 | 目标允许入账，但**按公司自身历史兑现率打折**并标"打折后"；**无历史可依 → 视为情景假设，不得进常态口径** | audit-gates.md G4 |
| **跨环节映射（跳步）** | 用**上游先行变量**直接映射结果，跳过中间环节：如跳过"产能 → 传导"用"中枢 ＋ 微利"当未来价格（两分叉退化成一个数）；或拿"产能 / 产能的源头"直接映射价格，跳过商品数量、库存、进口等环节 | 结果只能由**直接自变量**解释；**逐跳**走，每跳写清乘数 / 时滞 / 方向；自检"隔了几跳"——**≥1 跳却直接连线即违规** | principles.md P6 |
| **比例映射水平** | 用比例（同比、涨幅、缺口率）直接映射绝对水平（价格、产量、利润），丢掉基数；跨轮次 / 跨公司 / 跨地区套用同一"比例 → 高点"关系 | 写成 `水平 = 基数 ×（1 + 相对变化）`，基数逐样本取真值；自检"同一比例配不同基数会不会得出不同水平" | principles.md P7 |
| **反转＝回归中枢** | 把"反转兑现"定义成"价格回到中枢"，于是算不出任何上行空间 | 反转是**超调**：分叉一用中枢（常态利润），分叉二用**上行路径**（超额利润） | principles.md P6 |
| **分叉复读** | 分叉二与分叉一相差在 ±20% 以内 | 触发 P6 告警，改用路径求和法（高位年口径）或回查链条 | valuation.md 第 5 条 |
| **均值幻觉** | 用"平均成本 / 平均增速"代表整体，被少数极端个体拉偏（平均工资 3 万 ≠ 大多数人 3 万） | 看**中位数**，且**同时看产出加权与主体数量加权**两种口径；两者常差很多 | principles.md P4 |
| **口径混淆** | 引用"占比 / 集中度 / 排名"却不说是哪种口径（前 N 家 / 规模场 / 上市企业 / 百万头以上） | 写清口径，并列出相邻口径做对照 | principles.md P5 |
| **旧数据** | 用两年前的成本 / 份额 / 格局推当前中枢，结构性变量已经漂移而不自知 | 结构性变量一律取最近一期，并标注时点 | principles.md P5 |
| **纯数据外推** | 把历史斜率 / CAGR 直接延伸到未来，不问驱动机制是否还在 | 先找现实机制（谁决策、动机、硬约束），再判延续 / 衰减 / 反转 | principles.md P5 |
| **二手数字** | 公司公告里逐家写着的成本 / 产能 / 销量，却去引用第三方"行业平均"当锚 | 先读公司自己的披露（含投资者关系活动记录表），按产量加权；第三方只做交叉验证 | principles.md P5 |
| **二手转述** | 用媒体摘要代替政策原文，把区间当点值、把"左右"省略 | 读原文；先确认是点值还是区间；区分目标与结果 | valuation.md |
| **一次性修复当趋势** | 把"疫病后恢复 / 从坑里爬出来 / 口径切换"造成的效率跳升，当成可持续增速线性外推 | 把效率增速**分解成"一次性修复 / 可持续提升 / 结构置换"**，前瞻只取后两类，并加天花板与减速约束 | principles.md P6 |
| **反算未核** | 用推导出的参数直接进入测算，从不把它反算回观测量 | **参数 × 总量** 必须等于已知总量；差距大就先查口径/时点/定义 | principles.md P7 |
| **残差反算** | 用倒推出来的残差去"校验"另一个数——用假设验证假设 | 校验输入必须独立于被校验对象；残差不得当校验基准 | audit-gates.md G2 |
| **单算法定论** | 只用一个公式算出一个数就下结论 | 同一结论**至少两种算法**，差异必须能解释；解释不了就回查 | principles.md P7 |
| **口径错配** | 头部/样本口径的参数被当作全国/整体使用；期间数除时点数 | 分子分母同口径；期间数配期间平均存量 | principles.md P7 |
| **反现实** | 结论要求某主体做违反其利益的事：亏钱还扩产、只够保本却扩张、长期做亏本买卖、账面亏就当它立刻退出 | 做「**行为主体检验**」：**扩产要赚钱、退出要亏钱**；再查成本 / 资金 / 时滞 / 能力四重约束 | principles.md P8 |
| **凭空想象** | 推算值答不出出处：拍脑袋塞系数 / 折算率（如"归母 = 单位净利 × 销量 × 0.68"）、凭感觉取折现率或增速、单点外推、拿行业平均顶替公司实际 | **每个推算值都要能溯源**（依据 + 时点）；**能从现实一步算出的绝不多加一层**；假设必须显式化并接受检验；答不出出处的删掉或降级为情景假设 | principles.md P9 |
| **跳闸门** | 只审了"引用真不真"，没审"推导成不成立"，让假设镀金 | 结论必须过 G1–G5：报表对账 / 禁残差反算 / 薄毛利无次要项 / 对称验证 / 禁结论先行 | audit-gates.md |
| **跳过审查环** | 直接采信子 agent 的结论：不做交叉验证，或不做现实审查，就把结果写进报告 | **审查环缺一不可**——信息过 B 交叉验证与 G 闸门、结论过主 agent 现实审查；退回必须写明理由，循环至通过 | delegation.md |
