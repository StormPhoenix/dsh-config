# 审查闸门（G1–G5）—— 结论必须过的五道关

> 本文件是 P9 第一硬规则的**落地执行条款**，也是"两道审查环"之外的**第三道环**。
> 触发背景：某次分析得出"分叉一 ≈4.6 元 / 分叉二 ≈39 元"，但 4.6 元依赖的"某笔期间费用"是从恒等式**倒推的残差**、"某项单位成本"是**未兑现的公司目标**、"完全成本口径"与"所得税规则"**均未核实**。规则（P9、勾稽、残差拆开）其实都写过，却没被执行——因为审查只审了"引用真不真"，没审"推导成不成立"。
> **一句话：B 环查引用，G 关查推导。缺 G 关，等于给假设镀金。**

---

## G1 报表对账关 —— 结论里每个数必须落到报表某一行

**规则**：凡进入结论（合理价、利润、增速、单位盈利）的数，必须能指到**财务报表的某一行**：

| 结论数 | 应指到的报表行 |
|---|---|
| 收入 | 营业收入（按业务分部） |
| 主营业务毛利 | 营业收入 − 营业成本 |
| 期间费用 | 销售费用 / 管理费用 / 研发费用 / 财务费用（**四项分列，不得合并成一个"费用"**） |
| 减值 | 资产减值损失 / 信用减值损失 |
| 其他损益 | 其他收益 / 投资收益 / 公允价值变动 / 营业外收支 |
| 税 | 所得税费用（并查附注：适用税率与税收优惠） |
| 归母 | 归属于母公司股东的净利润（并核**少数股东损益**） |

**判据**：

- 每个结论数旁必须写「**对应报表行 + 金额 + 时点**」。**写不出 → 该数不得进结论**，只能降级为"情景假设"并单列。
- **残差、公司目标、自算值三类，一律不得冒充报表数**：残差要拆开（见 G2）、目标要打折（见 G4）、自算值必须标"自算"。
- **只要报告出现"毛利""费用""单位盈利"这类自造口径，就必须给出与报表行的勾稽关系**（例：自造毛利 2.99 亿 = 营业收入 X − 营业成本 Y；两者必须自洽）。
- **禁用一个残差吸收一切**：把减值、其他收益、税、少数股东打包成一个"X 亿元费用"或"X 元/kg 价差"，即违反本关。

**强制收口**：报告须附「**结论数 → 报表行**」对照表；有任何一行对不上，结论作废、重来。

## G2 禁止用残差做反算校验（循环论证）

**症状**：`毛利 − 期间费用 = 归母` 里的"期间费用"，本身就是用 `毛利 − 归母 − 减值 + 其他收益` 倒推出来的。再用它去"反算校验"，等于**用假设验证假设**，误差再小也不算通过。

**规则**：

- **反算校验的输入，必须独立于被校验对象**。用 A 反算 B，A 就不能是由 B 倒推出来的。
- 恒等式**可以**倒推缺失值（见 P7 勾稽），但倒推出的值**必须标"自算估计"**，且**不得再当作校验另一数的基准**。
- 任何"误差 1.9%，校验通过"的结论，先问一句：**这个误差是用独立数据算出来的，还是用残差自己凑出来的？** 凑出来的，**不算通过**。

## G3 薄毛利公司 —— 取消"次要变量"档

**规则**：当 `(售价 − 完全成本) ÷ 售价` 低于 **15%**，或利润 < 收入 × 10%，该公司进入**薄毛利状态**，此时 P2 的"次要变量取保守值即可，不必深挖"**失效**：

- 利润是几个大数之差，**没有任何一行是次要的**——费用、税、口径、减值、非经常项，**每一行都能单独改变结论方向**。
- 优先级排序的判据要换：**不看变量的绝对大小，看"单位变动对利润残差的相对影响"**。
- 薄毛利状态下，**每一个损益行项都必须落到报表行**（走 G1），不得用"差不多"的数。

**判据**：若某行项金额 > 利润的 **50%**，它就不是参数，是**决定性变量**，必须单独取证。

## G4 对称验证 —— 去方向性偏置

**症状**：skill 里只有"不许算得太低"的规则（微利不取保本、成本按趋势外推、路径求和），却没有"验证乐观假设能否兑现"的对称要求 → 未兑现的目标、激进的高位价一路畅通。

**规则**：**每一个乐观输入，都必须用"已发生的、可核实的事实"证明其可达**：

| 乐观输入 | 必须拿什么证明（目标本身不算证据） |
|---|---|
| 降本目标 | 公司**已兑现**的降本历史 + 已投产降本载体（如新产线 / 新基地满产率）的**实测值** + 同业同规模降本斜率 |
| 溢价维持 | 最近**多期实际**溢价序列（判断是否在收窄） |
| 高位价 | 由**供给收缩深度 → 历史对应高位**自算（不得直接抄历史高点） |
| 销量 / 产能扩张 | 已建成产能 + 最近月度进度 + 资本开支趋势 |

**打折规则（G4 核心）**：公司目标 / 管理层指引**允许入账，但必须按公司自身历史兑现率打折**，并标"打折后"。
兑现率 = 历史上同类目标的**实际达成均值**；**无历史可依 → 视为"情景假设"，不得进常态口径**。

**对称判据**：报告必须**同时**给出"悲观情景"与"乐观情景"，且两者用**同一套验证标准**——不许对悲观项抠细节、对乐观项放行。

## G5 禁结论先行 —— 先取证、后结论

**症状**：先有目标价，再去凑支撑（先画靶再射箭）。表现为：结论已定，然后"找证据证明某个既定目标价"。

**规则**：

- **顺序不可逆**：先逐条核实输入 → 再由输入**生长**出结论。**禁止先定结论再找数。**
- 输入查不到 → **当场作废该输入**，不得用假设顶上去继续往下算。
- 结论必须是**输入的函数**，不是输入的"目标"。
- **自检**：把结论遮住，只看输入能否推出它；再换一个合理输入，看结论是否合理变化。做不到 → 说明结论先行了。

## 附：两个高频口径核查

- **完全成本口径**：引用公司"完全成本"前，**必须查清它含不含期间费用（尤其财务费用）**。
  - 若**含** → `售价 − 完全成本` 已是**净口径**，**再单减期间费用即重复扣减**（此项一次即可让合理价差出约 **2.5 倍**）。
  - 若**不含** → 才可另减期间费用，且该期间费用必须来自报表行（走 G1），不得是残差。
- **所得税口径**：先查该业务**实际适用税率与优惠**——**不得默认 25%，也不得默认 0**。
  - 例：生猪养殖（"牲畜饲养"）所得**免征**企业所得税（《企业所得税法》第 27 条 + 《实施条例》第 86 条）；但**屠宰、贸易等非养殖业务不必然免税**，须按业务拆分应税占比，并核**亏损结转**年限。
