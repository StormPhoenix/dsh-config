# 三个分叉模块

> SKILL.md 的 Step 6–8 落地细则。共享内核（派活检索 + 拆树 + 数据核验 + 五道闸门）只跑一次，三个分叉按**运行模式**裁剪。

## 目录

- 依赖关系
- 分叉一：当前合理价值
- 分叉二：未来价值
- 分叉三：炒作价值

---

## 依赖关系

```
共享内核（Step 2–5：派活检索 → 拆树 → 数据核验 → 五道闸门）
   │
   ├─▶ 分叉一 当前合理价值 ──┐
   │                          │  分叉二以分叉一的常态中枢为基准
   ├─▶ 分叉二 未来价值 ◀──────┘（±20% 交叉校验）
   │
   └─▶ 分叉三 炒作价值（独立，不依赖一 / 二）
```

**铁律**：分叉二**必须**在分叉一完成后跑；分叉三独立，任意时点可跑。三个分叉共用内核产物，**不得各自重新检索同一批数据**。

## 分叉一：当前合理价值

**回答**：不增长也值多少。

**输入（取自内核）**：成本梯队（完全成本 / 现金成本，两种加权）、实证微利锚、公司实际售价、成本外推、股本。

**专属分析**：

1. **动态视角**（P3）：用不可逆因素（成本结构）定中枢，可逆因素（价格波动）定波动。
2. **中枢可行性检验**（P4，五步）：成本梯队两种中位数 → 亏损面曲线（账面 / 现金）→ 现金成本线 → 历史耐受时长 → **产出形态检验**。
   - 让"半数以上主体长期亏损"的价格是**洗牌价**，不是中枢；合理中枢应让"大多数主体微利、少部分亏损"。
   - 常态中枢锚定**实证微利年**，不得用保本线（valuation.md 第 3 条）。
3. **常态利润** =（公司实际售价 − 常态成本）× 量；口径钉死见 `valuation.md` 第 1 / 3 / 4 条。
4. **合理价** = 常态利润 × 回本年限 ÷ 股本（算法见 `methods.md`，脚本 `scripts/repay_period.py`）。

**输出**：常态利润、分叉一合理价、成本分布表、产出形态表。

**校验**：常态口径必须能反算回最近一个**微利年**的实际归母，误差 >10% 即口径错配（valuation.md 反算校验）。

## 分叉二：未来价值

**回答**：反转 / 增长兑现后值多少。

**依赖**：**必须先有分叉一的常态中枢**（分叉二以它为基准做校验）。

**输入**：分叉一常态利润 + 产能收缩路径 + 传导时滞 + 高位价。

**专属分析（P6 链条，不许跳步）**：

1. **产能收缩**到哪（终点 + 时点）：驱动是亏损可承受时长，不是政策目标。
2. **传导**：时间（生物 / 物理硬时滞）+ 数量（效率对冲）。
3. **价格路径**：冲高 → 高位维持 → 回落；反转本质是**超调**，不是回归中枢。
4. **逐年利润路径**：价格、成本、销量三个变量都在动。
5. **路径求和法（高位年口径）**：合理价 = 高位年平均利润 × 回本年限 ÷ 股本；同时给出**含反转年的保守下界**（valuation.md 第 5 条）。

**输出**：上行路径表、高位年利润、分叉二合理价（主结论 + 保守下界）。

**校验（强制）**：算完必须比分叉二与分叉一——**相差在 ±20% 以内即触发「分叉二沦为分叉一复读」告警**，改用路径求和法或回查链条（valuation.md 第 5 条）。

## 分叉三：炒作价值

**回答**：短期资金愿意给多少。

**依赖**：独立——数据域与基本面不同（资金面 / 题材 / 筹码 / 情绪），不依赖分叉一 / 二。

**输入**：成交量与换手、融资余额、北向持股、股东户数、解禁日历、龙虎榜、题材热度、事件日历。

**专属分析**：

1. **题材与事件驱动**：有无可发酵的题材 / 催化剂、事件时点。
2. **资金面**：增量资金方向（融资、北向、主力净流入）。
3. **筹码结构**：股东户数变化、解禁压力、历史成本分布。
4. **情绪与拥挤度**：换手率、成交额相对历史分位。

**输出**：炒作价值区间、触发条件、证伪条件。

**纪律**：

- 分叉三结论**必须标注"资金驱动、非价值支撑"**，**不得进入分叉一 / 二的基本面测算链条**。
- 不得用 PE / PB 等中间比率表达炒作高低（P1）；用资金面可观测指标 + 历史炒作市值区间表述。
- 炒作价值**不构成投资建议**，须写明其无基本面支撑、可快速回撤。
