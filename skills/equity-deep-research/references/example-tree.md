# 实操参考：迭代树的结构（通用示例）

本文件只示范**树应该长成什么样**——命题骨架与 MECE 切法。
以下为**抽象结构**，不对应任何真实公司。

## 初始问题：自带的三分叉

> **① 当前状态下的合理价值是多少？　② 预期未来的合理价值是多少？　③ 是否存在炒作价值？**

初始问题直接落位成这三块，**不推导**；MECE 从这三块各自的下一层才开始用。

## 四条纪律

1. **恒等式不占层。** 节点必须是**需要调研的命题**；像 `利润 = 收入 − 成本 − 一税三费`、`收入 = 销量 × 单价` 这种恒等拆解是**定义、不是命题**，不单独占一层。
   做法：子 agent 调研 L2（利润会如何变化）时，**先回报**"这是什么性质的公司、利润实际由哪些变量驱动、哪些项根本不适用"；主 agent 据此直接 MECE 出下一层，并**砍掉不适用项**——如民生 / 免税行业直接砍掉"税"，价格与成本强联动时合并成"价差"。
2. **推导链不占层。** `价格 = f(供给, 需求)`、`供给过剩 = f(产能, 需求)` 这类"结论 → 原因"的推导不是层级；节点必须是**可查的事实**（产能、库存、消费、份额……），不用"由什么决定"这种元问题占位。
   由这条纪律派生出两条切法：
   - **需求归价格支，销量只查公司自身。** 需求是**行业大数**、由大环境决定，作用是改变供需平衡，所以它是**价格**的输入——需求放在**价格支**，再按产品性质分：**刚需看消费人口、非刚需看终端消费意愿**。而上市公司的销量**不随大环境需求同比例变动**：总需求下滑先冲击**低质产品的销量**，未必落到本公司，故销量支只查**公司自身的份额 / 竞争力**。同一维度只查一次，避免"需求"在两支重复出现。
   - **供需对比不占层。** "供给会不会过剩"不是节点，它是"**供给侧趋势 − 需求侧趋势**"的**结论**，在 Step 4 趋势差一步算出，不进树。
3. **同层 vs 下一层。** 同层 = 对同一父命题做一次 MECE 切开得到的**并列**子命题（共享一个维度、互斥穷尽）；下一层 = 只挑影响力最高的那一支**纵向追问**。不得把同层并列写成父子链条，也不得把父子写成同层并列。
4. **同一维度只查一次。** 一个变量（如"需求"）只在一支里查，不得在多支重复。
5. **派发口径只写"怎么查"。** 命题后的 `→` 只描述子 agent 的**调研方法 / 口径**（查什么性质、走哪条取数路径）；**不得罗列下一层已穷举的子命题当例子**——那些子命题本身就是下一层的节点，重复列举等于把答案写进问题。

## 骨架（每个节点都是命题）

```
L1 ① 当前状态下的合理价值是多少？
│  ├─ L2 利润会如何变化？  → 子 agent 调研：先回报公司性质与利润的实际驱动变量，并指出哪些项根本不适用
│  │  ├─ L3 主要产品的合理价格是多少？  → 子 agent 调研：先回报产品性质；再沿供给端、需求端分别找驱动变量，并指出哪些项根本不适用
│  │  │  ├─ L4 产能在怎么变化？
│  │  │  │  ├─ L5 存量产能在怎么变化？
│  │  │  │  ├─ L5 在建产能在怎么变化？
│  │  │  │  │  └─ L6 在建产能何时投产？
│  │  │  │  │     └─ L7 投产进度会不会推迟？
│  │  │  │  └─ L5 退出产能在怎么变化？
│  │  │  ├─ L4 库存情况如何？【非大宗商品基本不考虑】
│  │  │  ├─ L4 进口量在怎么变化？【不可贸易品 / 本地化服务基本不考虑】
│  │  │  ├─ L4 是否存在替代品？【独家 / 无近似替代品基本不考虑】
│  │  │  ├─ L4 非刚需：终端消费意愿在怎么变化？【刚需品基本不考虑】
│  │  │  └─ L4 刚需：消费人口在怎么变化？【非刚需品基本不考虑】
│  │  ├─ L3 销量能否维持？  → 子 agent 调研：公司自身的份额与竞争力（大环境需求下滑先冲击低质产品，未必落到本公司）
│  │  │  └─ L4 份额在怎么变？【专营 / 独家垄断基本不考虑】
│  │  │     ├─ L5 产品竞争力在怎么变？
│  │  │     ├─ L5 渠道 / 客户结构在怎么变？
│  │  │     └─ L5 有没有新进入者抢份额？
│  │  ├─ L3 成本能否维持？  → 子 agent 调研：上游供给格局、有无新增供给、向本公司传导的时滞
│  │  │  └─ L4 上游投入品价格处在周期什么位置？【无周期性上游投入（软件 / 人力服务）基本不考虑】
│  │  │     ├─ L5 成本红利能否留存？
│  │  │     └─ L5 这个红利会不会反转？
│  │  └─ L3 费用能否维持？  → 子 agent 调研：各项期间费用的历史水平与有无刚性上升项
│  │     └─ L4 期间费用还有多少压缩空间？
│  │        ├─ L5 销售费用还有多少空间？
│  │        ├─ L5 管理费用还有多少空间？
│  │        └─ L5 财务费用还有多少空间？
│  └─ L2 年化收益相对其它是否合理？  → 子 agent 调研：估值相对同业与自身历史的位置
│     ├─ L3 回本年限是多少？  → 子 agent 调研：按回本年限法取市值、可持续利润、分红与增速假设
│     │  ├─ L4 用哪个利润口径？
│     │  └─ L4 买价取市值还是企业价值？
│     ├─ L3 能不能达到门槛回报？  → 子 agent 调研：门槛回报 9.6% 隐含的回本年限上限与对应合理价
│     │  ├─ L4 门槛 9.6% 对应几年回本？
│     │  └─ L4 当前价对应多少年化？
│     └─ L3 与同业、自身历史比如何？【无同业 / 次新股基本不考虑】  → 子 agent 调研：取同业样本与自身历史区间做对比
│        ├─ L4 相对同业在什么分位？
│        └─ L4 相对自身历史在什么分位？
│
L1 ② 预期未来的合理价值是多少？
│  ├─ L2 增长从哪来？  → 子 agent 调研：增长来源拆解、各自时间表与历史兑现记录
│  │  ├─ L3 存量还能不能增长？  → 子 agent 调研：存量业务的量、价各自还有多少上升空间
│  │  │  ├─ L4 存量需求还在不在增长？
│  │  │  │  └─ L5 行业需求天花板在哪？
│  │  │  └─ L4 还有没有提价空间？
│  │  │     └─ L5 提价会不会丢份额？
│  │  ├─ L3 新品能贡献多少？【无新品管线（公用事业 / 单一产品）基本不考虑】  → 子 agent 调研：新品管线的进度与历史兑现记录
│  │  │  ├─ L4 管线里有哪些新品？
│  │  │  │  └─ L5 上市时间表是什么？
│  │  │  └─ L4 历史上新品兑现得怎么样？
│  │  └─ L3 外延能贡献多少？  → 子 agent 调研：并购 / 外延计划的进度与整合记录
│  │     ├─ L4 有没有明确的并购标的？
│  │     └─ L4 并表节奏与整合效果如何？
│  └─ L2 增长能持续多久？  → 子 agent 调研：行业总需求的天花板、公司份额上限、替代与竞争格局
│     ├─ L3 内生可持续增长率是多少？  → 子 agent 调研：按 g = ROE × 留存率取历史水平与可持续性
│     │  ├─ L4 ROE 还能不能维持？
│     │  │  └─ L5 净利率与周转率各会怎么变？
│     │  └─ L4 留存率会不会变？
│     └─ L3 超出内生的部分靠什么补？  → 子 agent 调研：超额增长的资金来源
│        ├─ L4 靠加杠杆？
│        ├─ L4 靠降分红？
│        └─ L4 靠外延？
│
L1 ③ 是否存在炒作价值？
   ├─ L2 未来 90 天有没有确定事件？  → 子 agent 调研：未来一季度的确定日程
   │  ├─ L3 定期报告会改变盈利预期吗？  → 子 agent 调研：报告披露日程，与市场预期做对照
   │  │  ├─ L4 市场当前预期是多少？
   │  │  │  └─ L5 卖方预期隐含什么假设？【无卖方覆盖基本不考虑】
   │  │  └─ L4 实际可能差多少？
   │  │     └─ L5 差异来自哪个业务？
   │  └─ L3 关键许可 / 专利到期会改变什么？【无牌照 / 专利约束基本不考虑】  → 子 agent 调研：许可 / 专利到期的时间表与影响范围
   │     └─ L4 是否已被定价？
   ├─ L2 资金面支不支持？  → 子 agent 调研：资金与筹码的动向
   │  ├─ L3 主力资金在流入还是流出？  → 子 agent 调研：主力资金的流向与构成变化
   │  │  ├─ L4 机构在加还是减？
   │  │  └─ L4 北向在加还是减？
   │  └─ L3 筹码结构松不松？  → 子 agent 调研：股东户数、筹码集中度、解禁日程
   │     └─ L4 是谁在卖？
   │        └─ L5 板块贝塔还是个股阿尔法？
   └─ L2 情绪位置如何？  → 子 agent 调研：股价位置与市场情绪
      └─ L3 股价处在什么位置？  → 子 agent 调研：股价位置的量化指标
         ├─ L4 相对自身历史在什么分位？
         └─ L4 相对板块在什么分位？
```

**读法**：树自上而下是「问题 → 子问题」，**每个节点都是能回答"是 / 否"或"多少"的命题**；横向同一层必须 MECE；最深路径 ≥ 6 层。命题后的 `→` 是该命题的**派发口径**——只写子 agent 该**怎么查**（方法 / 口径），不重复下一层已穷举的子命题。命题后的 `【】` 是**该行业不适用项**——命中就不必查、直接砍掉（如非大宗商品不看库存、刚需品不看消费意愿）；它是**按现实判断的行业前提**，不是可选项。
