# 核心原则 P1–P9（怎么想）

> 这九条统领全树，是"怎么想"的规则。"怎么做"见 `workflow.md`（拆树机制）、`valuation.md`（估值纪律）、`audit-gates.md`（审查闸门）。
> **P9 是第一硬规则**——所有推算数据必须能溯源、符合现实，不许凭空想象。

### P1 两个方向（统领全树）

只有两个方向，所有分支都必须落在其中：

- **一切数据归于利润。** PE、E/P、ROE、PB 都是利润的衍生指标，不是本质。本质只有一句话：**花多少钱买下这家公司，它每年赚的利润，多少年能把这笔钱赚回来**。回本即 100% 收益，再按年限折成年化。
  - **禁令**：正文、KPI、结论中**不得出现 PE、PB、市盈率、市净率**等中间比率——它们既不是证据，也不是结论。
  - 表达"贵还是便宜"，只写**回本年限**与**年化收益**；表达"资产质量"，只写能连回利润的口径；"股息率"必须写成"**利润中分到股东手上的部分**"再参与讨论。
- **一切因子归于供需。** 收入、价格、成本、份额，全部还原为供给与需求两侧的力量对比。

这两个方向同时也是**剪枝标准**（见 P5）。

### P2 优先级 —— 研究的第一步是排序，不是列清单

> 这条规则不是做一次就完，而是**绑定到每一次 MECE**：每切一刀，就立刻排一次优先级，再把纵向思考优先给影响力最高的那一支（见 `workflow.md`）。

#### 一、变量权重排序（决定把精力放哪）

**做法**：对每个候选变量，算「单位变动 → 对结论的影响」，按影响排序。

| 权重 | 判据 | 处理方式 |
|---|---|---|
| **决定性** | 单位变动即可**改变结论方向** | 绝大部分分析深度给它 |
| **重要** | 能显著改变结论**幅度**，但不改方向 | 作为核心参数，给区间 |
| **次要** | 只在参数层面**微调**结论 | 取保守值即可，不必深挖 |
| **背景** | 不直接进入利润，只影响**节奏** | 单独说明，不占分析篇幅 |

**规则**：

- 排序必须**用数字算出来**（做敏感度），不能凭感觉
- 若某个低权重项在输出里占了大量篇幅，说明排序做错了——**这是最常见的失焦方式**
- 决定性变量往往只有一个。找到它，其余都退为参数
- **对决定性变量，必须从它自身再长一棵完整的树**（MECE 切开 + 纵向下钻 ≥6 层），不能只在参数层面推演一句话——**这是本方法最容易偷懒的地方**
- 常见失手：把"价格"定为决定性变量，却只写"供给过剩约 X%"就下结论。价格本身也是"结果"，它同样要按同一套规则拆到供给 / 需求 / 缓冲 / 成本锚，并逐层落到数据

**例**（跨行业对照，仅示意思路，不构成套路）：

| 类型 | 决定性变量 | 次要变量 | 背景变量 |
|---|---|---|---|
| 大宗商品类 | 产品价格（由供需决定） | 自身产量 | 政策、资金面 |
| 品牌消费类 | 提价能力 / 渠道库存 | 产能 | 宏观景气 |
| 成本敏感制造 | 上游原料价格 | 销量 | 汇率 |
| 政策管制行业 | 政策阈值（价格 / 准入） | 经营效率 | 管理层 |

> 判断标准很简单：**问"这个变量变一个单位，结论会不会翻"**。会翻的是决定性变量，只微调的是次要变量。

> 同一层"先挖哪一支"见 `workflow.md` 的「排」；异常数据的额外优先权见 `workflow.md` 的异常优先。

### P3 动态视角 —— 趋势惯性 · 传导时滞 · 不可逆点

静态地看"现在是多少"会得出错误结论。判断任何驱动变量时，先过这三道。

#### 一、看变化率，不看静态值（趋势有惯性）

- 一个**正在加速的趋势，突然刹车的概率很低**——更可能是继续加速、或缓慢减速。所以要看**它自身变化率的变化**，而不是它的当前水平。
- 做法：把关键驱动变量的**时序**列出来，看每期的变化量、以及变化量的变化（加速 / 匀速 / 减速），再据此外推下一期。
- **外推的前提是"连续同向且幅度在扩大"**；单点异常不构成趋势，不能外推。
- 推论：若多个驱动变量方向一致（例：供给在收缩、需求在下移），则**两个方向都不会突然反转**，结论可以给得更坚决。

#### 二、传导有时滞（产能 ≠ 供应）

- 从"产能变化"到"商品供应变化"之间存在**硬时滞**（生物周期、船运、建厂、审批）。今天看到的商品价格，反映的是若干期之前的产能；今天做的产能决策，也要若干期之后才体现在供应上。
- 做法：画出**时滞管道**——"哪个窗口的供应，由哪个窗口的产能决定"，逐窗口推。这能解释许多看似矛盾的并存现象（例：价格已经见底，供给却依然宽松——那只是时滞）。
- 推论：**预期能兑现的时间表，必须由时滞决定**，不能用"应该快了"替代。

#### 三、只算不可逆的点（市场炒预期，能算准的是不可逆）

- 市场在炒预期，而预期可以来回摆动。**可逆的因素（价格波动、原料成本、短期扰动、情绪）会自我修复，算它意义有限。**
- **不可逆的因素一旦发生就长期锁定，这才是可以明确计算的**：技术单向上行（效率、良率）、生物 / 物理硬约束（产能恢复的最短时间）、行政约束（政策存续期内）、结构性变迁（人口、消费习惯）。
- **判据**：问"这件事发生后，能不能在可预见期内回到原状？"不能 → 不可逆 → 进入测算主链；能 → 可逆 → 降为参数或背景。
- **用不可逆因素定"中枢"，用可逆因素定"波动"。** 把可逆的周期高点当成新中枢来估值，是这类分析最典型的错误；反过来忽略不可逆因素使中枢逐年漂移，会系统性高估。
- 类比：某地区的电解铝厂被炸，产能在数年内是永久损失——可以精确计算；而"战争推高油价"会被库存、增产等对冲——说不准。**优先算前者。**

### P4 均衡中枢的可行性检验 —— 亏损面与可承受时长

推算出任何"中枢 / 均衡值"之后，**必须再做一次可行性检验**：这个水平在现实里站得住吗？

**检验逻辑（反证法）**：若某个价格让行业里大量主体长期亏损，它们必然退出 → 供给收缩 → 价格被推回。
**所以中枢不可能长期低于"让行业多数存量产能保本"的水平**；同时它也不会高到吸引外部大量进入。
均衡就落在"**已入场的多数能接受、外部入场者嫌弃收益率偏低**"之间。

**五步做法**：

1. **画成本梯队**：按梯队（龙头 / 腰部 / 长尾）列出**完全成本**与**现金成本**，并**同时记录两种占比**：
   - **占产出（销量）的比重** —— 决定供给与价格
   - **占主体数量（家数 / 户数）的比重** —— 决定出清速度与政策干预压力
   - **最常见的错误：用"平均成本"。** 平均会被少数极优秀者拉偏——正如"中国人平均工资 3 万"不代表大多数人的工资。
     **正确做法是看中位数，而且要同时看两种加权下的中位数**：产出加权中位数、主体数量加权中位数。
     两者常差很多（例：某行业产出加权中位成本 13.3，主体数量加权中位成本 15.5——差 2 个单位，全部来自"长尾被龙头平均掉"）。
   - **推论**：价格能让"多数产出"保本，却往往无法让"多数主体"保本；后者靠退出与政策解决，不能作为价格的锚，但会给价格加一个溢价。
2. **算亏损面曲线**：对每个候选水平，**分两种加权**各算两个比例——
   - **账面亏损面** = 完全成本 > 该水平的主体/产出占比 → 决定"意愿性退出"的强度
   - **现金亏损面** = 现金成本 > 该水平的主体/产出占比 → 决定"被迫退出"的强度
3. **找现金成本线**：**跌破现金成本线，主体开始失血、被迫出清；在其之上，只剩意愿性退出。** 这条线是中枢的硬下界。
4. **查历史耐受时长**：翻历史同类周期，看主体**能扛多久**（亏损持续了多久、期间产能收缩了多少）。
   用它判断"当前周期还剩多久"——**亏损时长已进入历史区间，说明反转临近**。
5. **检验「产出的形态」**（最关键的一步）：**合理的中枢，应让产出呈现"正常形态"**——
   **少部分主体有利润 · 大多数有微利 · 一部分保本 · 少部分亏损。**
   - 拿候选水平去套成本分布，**数一数**：多少主体在"大赚 / 微利 / 保本 / 亏损"？
   - **若某个价格让"半数以上主体"长期亏损，那不是合理价格，是"洗牌价"**——出清尚未完成时的过渡态。
     它可以（而且经常）是周期底部的实际成交价，但**不能当作中枢**。这是本方法最容易犯的错：**用底部的洗牌价当长期中枢，系统性低估。**
   - 反过来，若价格让几乎所有人都赚钱，那是**情绪上沿**，必然引来扩产，也不是中枢。
   - **实操捷径**：去找一个**实证锚**——历史上某段时间，官方口径明确说是"全行业微盈"的那个价格，它通常就是中枢的量级。

**输出格式**：一张「梯队 → 两种占比 → 完全成本 / 现金成本 → 两种中位数」的对照表；一张「水平 → 产出加权亏损面 / 主体加权亏损面 → 产出呈现的形态」的对照表；一张「历史周期 → 亏损时长 → 累计产能收缩」的对照表。

**两条通用推论**：

- **中枢的下界 = 让"满足需求所需的产能"多数保本的水平**（产出加权）；上界 = 吸引新进入者的水平。
  "让多数**主体**保本"的水平通常远高于下界，且**不可持续**（会让低成本龙头获得暴利、进而扩产把价格打回）——所以它是"情绪/政策的上沿"，不是中枢。
- **用亏损时长判断时点，用成本分布判断水平，用产出形态判断"这是不是中枢"**——三个问题，别混。

### P5 基于现实 —— 数据是痕迹，不是现实

**每个数据在进入测算前，先过三问：**

1. **口径**：它是哪一种统计口径？同一年、同一行业、同一个"占比"，换个口径能差近一倍。
   例：集中度——**前 4 家 22.6%**、前 10 家 29.7%、"百万头以上 39 家"41%。说"头部占 41%"，就等于把口径偷换了。
   → **引用占比 / 集中度 / 排名，必须写出是哪一种口径，并列出相邻口径做对照。**
2. **时点**：它是什么时候的？**成本、份额、效率、产能格局、政策这类结构性变量每年都在漂。**
   例：某行业长尾主体的成本原本比龙头高 3 元，两年后只高 0.7 元——"长尾必然被出清、成本中枢下移"的推论因此失效。
   → **结构性变量一律取最近一期，并在正文标出时点。**
3. **机制**：这个数字由什么现实力量造成？那个力量现在还在不在？

**取数顺序（硬规则）**：**公司自身的披露 > 官方统计 > 第三方汇编。**

- **公司自己就报了成本、产能、销量、份额——先去看它的公告**（年报 / 半年报 / 月度经营数据 / **投资者关系活动记录表**）。
  上市同业之间可横向对照，并按**各自的产量加权**得到"头部加权成本"。
- **官方统计**（部委、统计局、行业协会）用于行业总量与分布；**第三方汇编只做交叉验证**，不能当唯一来源。
- 反例：某行业的成本，公司公告里逐家写着，却去引用一份"行业平均"的第三方汇编——那是把**最不可靠的二手数字**放在了最关键的锚位上。
- **同一指标出现两个官方口径且相互矛盾时（例：散户成本 13.2 vs 16~17），不要二选一，要把分歧本身写出来**，并说明它对结论的影响有多大。

**趋势必须用现实机制推，不能用历史统计外推。**

- 纯数据外推（把过去 N 年的斜率 / CAGR 直接延伸到未来）隐含了"驱动机制不变"的假设，而这个假设通常不成立。
- 正确做法：**先找到驱动这个趋势的现实机制——谁在做决策、他的动机是什么、受什么物理 / 生物 / 制度硬约束——再判断这个机制会延续、衰减还是反转。**
- 例：某行业单位成本连年下降。纯外推会说"继续降"；回到现实先要问：降本来自技术扩散、原料周期还是规模效应？源头是否枯竭？对手会怎么反应？
- **价格、份额、成本都是"行为的结果"**，行为会随环境改变；只有受物理 / 生物 / 制度硬约束的部分（产能恢复的最短时间、技术单向扩散、人口结构）才适合外推。

**一句话**：数据是现实的痕迹，不是现实本身。每个趋势都要能说清"它由谁的行为、受什么约束驱动"——说不清，就不许外推。

### P6 周期品的价格链条 —— 从产能到估值，不许跳步

周期品的价格**不是"回到中枢"，而是"供需缺口"的函数**。所以推演必须按链条走，**每一步的输出是下一步的输入**：

$$\textbf{产能} \rightarrow \textbf{传导} \rightarrow \textbf{价格} \rightarrow \textbf{利润} \rightarrow \textbf{估值}$$

**最常见的致命错误**：跳过前两步，直接用"成本中枢 ＋ 微利"当未来价格。那是**把结果当输入**——等于假设"未来就是常态"，**否定了周期本身**；而且会让"当前状态的合理价值"与"预期未来的合理价值"两个分叉**退化成同一个数**（分叉二沦为分叉一的复读）。

**通用规则（不限周期品）：结果只能由「直接自变量」解释，不得跨环节映射。**

- 一个结果变量（价格、利润、份额）只能由与它**同层**的直接自变量解释——**价格由「商品数量」与「需求」解释**。凡是影响那个直接自变量的**上游因素**（产能、产能的源头），都只是链上的**一环**，只能通过**逐跳传导**影响结果，**不得越过中间环节直接映射**。
- **每跳必须写出三件事，并给出现实依据**：**乘数**（衰减 / 放大）、**时滞**、**方向**。
- **跳步会同时犯三个错**：**乘错数**（每跳都有衰减，跳 n 跳就少乘 n 个系数）· **算错向**（中间环节常含**反向作用**——下游反馈回上游，跳过后方向都可能错）· **弄错主次**（短尺度上，某个中间环节——库存、缓冲、二次加工——可能比最上游更能决定结果）。
- **自检**：起点与终点之间**隔了几跳**？**≥1 跳却直接连线 → 违规**。**是否存在一个"更直接"的中间变量？** 有就必须用它，不许越过。
- **例**：用"上游原料产量变化"直接映射"下游产品价格"，跳过了库存缓冲、替代品、传导时滞、需求弹性四跳——**偏差无上界**。正确做法是逐跳推，每跳的输出是下一跳的输入。

#### 一、每一步要产出什么

| 步 | 产出 | 关键 |
|---|---|---|
| ① 产能会收缩到哪 | 收缩的**终点**与**时点** | 驱动是**亏损的可承受时长**，不是政策目标。终点＝让行业回到"多数主体微利"的那个产能 |
| ② 传导 | **时间**与**数量**两层 | 时间＝生物 / 物理硬时滞；数量＝产能变化被**效率**对冲掉一部分 |
| ③ 价格能到哪 | 一条**路径**：冲高 → 高位维持 → 回落 | **不是回到中枢**。反转的本质是**超调**——缺口在扩产到位前一直存在，价格必然冲过中枢 |
| ④ 利润 | 一条**逐年路径** | 价格、成本、销量三个变量都在动 |
| ⑤ 估值 | 对**路径**求和（回本法）或折现 | 不是"中枢利润 × 回本年限" |

#### 二、拆供需的两条 MECE 腿（唯一正确的切法）

$$\text{供给} = \underbrace{\text{数量}}_{\text{例：产能}} \times \underbrace{\text{效率}}_{\text{例：单产}} \qquad \text{需求} = \underbrace{\text{基数}}_{\text{例：人口}} \times \underbrace{\text{强度}}_{\text{例：人均消费}}$$

$$\text{价格} \leftarrow \text{供给增速} - \text{需求增速}$$

两条腿缺一不可：

- **只拆数量、不拆效率** → 会推出"产能降了供给就降了"（错，效率在补）
- **只拆供给、不拆需求** → 会推出"产能收缩价格必涨"（错，需求可能跑得更快）

#### 三、四条水平线并排法（本节的要点）

**把「源头产能 → 实际供给量 → 需求量 → 价格」四条线，用水平值并排放在同一时间轴上。**

| 线 | 内容 | 时点 |
|---|---|---|
| ① 源头产能 | 决定未来供给的产能指标 | 领先时滞 |
| ② 实际供给量 | 当期实际产量 / 销量 | 由 ① 右移时滞得到 |
| ③ 需求量 | 当期实际需求量 | 当期 |
| ④ 价格 | 当期价格水平 | 当期 |

**四条都必须是「水平值」，不是同比增速。** 这是最容易搞反的地方：

- **为什么不能用增速**：价格由供给的**存量水平**决定，增速只保留"变化率"，把"水平"丢掉；且增速有基数效应（**比例不能确定水平、基数不可丢**——见 P7-三之三）。
  **反例**：只把"产能同比"与"价格同比"并排，会漏掉"**同等产能水平下、价格逐年下移**"这一整层信息——而那恰恰是效率与需求变化造成的。
- **读法**：
  - **② − ③** 的差 = **供需缺口**；**④** 是它的价格表达
  - **① → ②** 的比率 = **效率**（单位产能的产出）
  - **② 与 ③ 各自的走向**：一个在增、一个在降 → 价格必然承压，且**压力来源可分离**
  - **④ 相对 ② − ③ 的位置是否逐年漂移** —— **漂移量本身就是要预测的东西**，不是可以直接套用的换算率

**水平对照的价值在于它能暴露「漂移」**：同一产能水平对应的价格若逐年在变，
说明"数量"已经解释不了价格，**必须把效率与需求两条线拉进来**。**漂移越大，越不能直接套历史水平。**

**数据粒度**：逐月数据不好拿时，**年度即可**——官方每年都有，四条线一样成立。

**看漂移要看"同一口径、同一月份"的跨年对照**（消除季节性），不要跨月份比。

**效率序列必须分解驱动，不许把"一次性修复"当趋势外推。**

一个效率指标的历史提升，通常由三类驱动混合而成，**只有第二、三类可以外推**：

| 类型 | 例子 | 能否外推 |
|---|---|---|
| **一次性修复** | 疫病后成活率恢复、产能利用率从低点回升、政策口径变化 | **不能**。它是"从坑里爬出来"，不是"往前跑" |
| **可持续提升** | 品种 / 工艺升级、管理进步 | 能，但**受扩散周期约束** |
| **结构置换** | 高效率主体占比上升（规模化率） | 能，但**储备有限**——占比接近上限即失效 |

**做法**：把历史增速按这三类拆开，**前瞻增速 = 历史增速 − 一次性修复贡献 − 已耗尽的结构红利**。
另需加两道约束：**生物 / 物理天花板**（存在硬上限）、**减速律**（越接近上限，增速越低）。

**判据**：如果一项效率指标的历史增速远高于同行/国际水平，先假定它含有一次性修复，把它拆到能解释清楚再外推——**说不清增速从哪来，就不许外推**。

#### 四、临界条件（同比法的直接产物）

由"价格 ← 供给增速 − 需求增速"立即可得一个**可证伪的临界条件**：

$$\text{产能同比降幅} \;>\; \text{需求增速} + \text{效率增速}$$

不满足 → 磨底；满足 → 价格上行。**它比任何"拐点预测"都硬**，因为它是恒等式推出来的，只依赖可观测的同比。
**注意：它只给方向，不给水平**——水平仍须按 P7-三之三，用**绝对差额**读数，不得由同比直接换算。

#### 五、反转 ≠ 回归中枢（分叉一 / 分叉二的分工）

- **中枢**由不可逆因素（成本结构）决定，是**长期**的 → 对应**分叉一**（常态利润）
- **反转**由供需缺口决定，是**短期**的、且**必然超调** → 对应**分叉二**（上行路径的超额利润）
- 判据：**若"预期未来的价值"里没有超出常态的那部分，说明链条被跳步了。**

### P7 三重校验 —— 数据要核验，计算要互验

**没有任何一个数字可以"拿来就用"，也没有任何一个结果可以"算一遍就交"。**

#### 一、反复核验（数据）

- 同一数据**至少两个独立来源**；写清各自的口径与时点
- **两个官方口径相互矛盾时，不要二选一，把分歧本身写出来**，并说明它对结论的影响有多大
- 来源等级排序：**一手（公司/监管/统计部门原文）＞ 权威二手（行业协会、专业数据商）＞ 转述（媒体、研报引用）**

#### 二、反算核验（数据 → 参数，最容易被跳过的一步）

**任何一个从数据推导出的参数，都必须能反算回观测量。反算结果与公布值差距过大 → 先解决差异，差异未解决前不得使用该参数。**

反算差距大的三种常见原因，按可能性排序：

| 原因 | 表现 | 处理 |
|---|---|---|
| **口径不同** | 公布值是"头部/样本"口径，被当成"全国/整体"用 | 用总量反算校验：若参数 × 总量 ≠ 已知总量，即为口径错配 |
| **时点/期间错配** | 分子用期间数（年产量）、分母用时点数（年末存量） | 换用**期间平均值**重算 |
| **定义不同** | 同名指标口径不同（如含有/不含某环节） | 查定义原文，标明差异 |

**实操**：把"参数 × 总量"算回来，与实际总量比。差距超过几个百分点，就不许直接用。

**年度值必须能由月度/季度值加总核验。** 引用二手"年度均价 / 年度总量"前，用官方月度序列自己算一遍并对照——
二手的年度值经常是错的（差异足以让整张弹性表作废）。
**能用一手月度序列自算的，就不引用二手年度汇总。**

#### 二之二、勾稽 —— 用恒等关系「倒推」缺失值、「核验」存疑值

**数据之间不是孤立的，它们之间存在恒等关系。利用这些恒等关系，可以做到两件关键的事：**

| 用途 | 做法 | 例 |
|---|---|---|
| **倒推缺失值** | 已知 A、B，用 `A ÷ B = C` 或 `A × B = C` 把 C 算出来 | 只有季度值 → 用季节性占比推出全年；缺"人均消费" → 用 `消费总量 ÷ 人口` 算出 |
| **核验存疑值** | 两个独立来源不一致时，用第三个恒等关系当裁判 | 消费量两个口径 5,816 vs 5,680 → 用 `人均 × 人口` 反算，看哪个自洽 |

**常用恒等关系（自变量行业不同，形式不同）**：

- **量的分解**：总量 = 数量 × 单价 × 单产
- **量的守恒**：供给 − 需求 = 库存变动 + 净流出
- **链式传导**：上游产能 × 效率 = 下游产量

**三条使用规则**：

1. **勾稽结果若与常识不符，先怀疑数据而不是怀疑常识**（例：算出"净出口为正"——而该国是净进口国，说明序列不同源）
2. **倒推出来的值必须标为"自算估计"**，与一手数据区分开
3. **两个口径矛盾时不二选一**，把差异写出来并说明对结论的影响

#### 三、多方式交叉（计算 → 结论）

**同一结论至少用两种不同算法算一遍，差异必须能解释。**

- 估值类：回本年限法 / 路径求和法 / 折现法 / 收益率法
- 增速类：驱动分解法 / 反算法 / 对比法
- **差异能解释** → 说明白差异来自哪个假设（例："两条路径只差过渡期的亏损"）
- **差异解释不了** → 至少有一种算法错了，必须回查，不许取平均糊过去

#### 三之二、趋势 —— 每类数据都要算变化趋势，用「趋势差」推结论

**水平值说明"现在在哪"，趋势说明"正在往哪走"。两者都要，缺一个结论就会偏。**

**做法**：对每一条线算 **CAGR 或斜率**，列成一张表，然后看**几条趋势之间的关系**：

| 步骤 | 内容 |
|---|---|
| ① | 算出每一类数据的趋势（逐项给出各自的年变化率） |
| ② | 找**趋势差（剪刀差）**：供给侧趋势 − 需求侧趋势 |
| ③ | 用**趋势差**解释价格趋势，反推出趋势弹性 |
| ④ | 预测时**把趋势差外推**，而不是把价格水平外推 |

**为什么用趋势差而不是水平差**：水平差含一次性的基数效应与季节性；趋势差是"两条线各自的长期速度之差"，更能代表结构性压力。

**三类数据的趋势通常方向不同，这正是关键信息**：

- 供给侧（产量 / 供给量）在**增**、需求侧（人均消费）在**降** → 价格必然承压，且**压力来源可分离**
- 若只有供给侧在变、需求侧平 → 压力是周期性的，会回归
- 若两侧**同向背离**（一增一降）→ 压力是**结构性**的，不会自动回归

**判据**：**趋势差决定方向与量级；水平值决定位置。** 两者结论冲突时，以趋势差解释的**方向**为准，以水平值校准**幅度**。

#### 三之三、比例不能确定水平 —— 基数不可丢（优先用「绝对量」）

**比例与水平是两种量纲，不能跨类映射。** 比例（同比、涨幅、占比、缺口率）是**无量纲**的；水平（价格、产量、利润、规模）是**有量纲**的。**前者不能单独决定后者。**

**规则**：

1. **任何「比例 → 水平」的映射，必须显式写成 `水平 = 基数 ×（1 + 相对变化）`**；基数**逐样本、逐期**取各自的真实值，**不得默认恒定**。
2. **跨样本套用「比例 → 水平」关系是重灾区**（跨周期轮次、跨公司、跨地区、跨品种）——每个样本的基数不同，套用即错。
3. **基数自身要有现实锚**（例：周期低点由现金成本决定），不能自由取值。
4. **允许的映射只有两种**：比例 → 比例、水平 → 水平；**跨类必须显式带基数**。
5. **自检**：同一比例配不同基数，会不会得出不同水平？**会 → 该映射无效，必须补基数**。

**例**：两个周期同样"产能去化 −9%"，但一个从低点 11.5 起涨、另一个从 14.6 起涨——套同一个"历史对应高点"，绝对结果差 6 以上。**拿比例直接映射绝对值，等于默认基数相同。**

**由此推出正确做法——用绝对量、算绝对差额**：

- **反面**：拿"产能同比""供需缺口百分比"去乘一个弹性系数 → 出来的数看着精确，其实丢掉了"现在处在什么水平"。
- **正面（推荐链条）**：
  1. 用**绝对量**算出未来的**供给量**
  2. 用**绝对量**算出未来的**需求量**（按逐年增量外推）
  3. 算**绝对差额**（供给 − 需求）
  4. 用历史上「**绝对差额 → 价格**」的关系**读数**

**为什么这样能避开"漂移"**：**差额同时含了供给侧与需求侧两条线的信息，漂移被自动吸收。**
用单一变量（产能、年份）或增速做自变量，就会出现逐年系统性漂移；用双边差额则不会。

**自检方法**：**看残差有没有系统性趋势。**

- 残差逐年单向漂 → 自变量漏了东西（漏了需求侧或效率），关系不可外推
- 残差无系统性趋势（正负交替） → 该自变量已把主要信息吸收，可以用来外推

**同理，趋势也要用绝对增量**（例："消费量年均 +68 万吨"），比"年均 +1.2%"更能直接进入差额计算。

#### 四、口径一致性（贯穿以上三步）

**分子与分母、参数与总量、时间与主体，必须同口径。**

- 全国参数只能配全国总量；头部参数只能配头部总量
- 期间数配期间平均存量，不配年末时点数
- 混用口径是上述所有错误的共同根源

### P8 现实审查 —— 结论必须通过「行为主体检验」

**分析完成之后、交付之前，必须把结论反过来审查一遍：这个结论要求某个经济主体做出"违反他自身利益"的行为吗？**

只要答案是"是"，结论就是反现实的，无论算式多漂亮。

#### 一、检验方法

把结论里每一个**主体行为**单独拎出来，写出"**他为什么会这么做**"。写不出来 → 结论不成立。

#### 二、三类最容易反现实的行为

| 行为 | **真实触发条件** | 常见的反现实写法 |
|---|---|---|
| **扩产** | 价格或回报**显著高于成本**、对未来有信心、且有资金 | "价格到 X 元 → 大家就扩产"（X 甚至低于成本） |
| **退出** | **现金**亏损持续够久 + 资金耗尽 | "账面亏损 → 立刻退出" |
| **持续亏本经营** | 只有在有明确退出成本 / 补贴 / 赌周期时才会出现 | 让某主体长期做亏本买卖 |

**核心判据一句话**：**扩产要赚钱，退出要亏钱。**

- 若结论说"价格涨到 A 就扩产"，先问：**A 高于成本多少？** 若 A 只够保本，没人会扩产——**价格反而会在成本线以上站得更久**。
- 若结论说"亏到 B 就退出"，先问：**是账面亏还是现金亏？亏了多久？** 账面亏可以扛，现金亏才走人。

#### 三、必须一起检验的"约束链"

- **成本约束**：长期价格不能低于**全行业现金成本**（否则全行业失血，不可持续）
- **资金约束**：已连续亏损 N 个季度的主体，不能假设它继续硬扛（**连续若干季度现金流亏损**即触发被动退出）
- **时滞约束**：主体反应有物理 / 生物时滞，不能假设瞬时响应
- **能力约束**：不是"想不想"，还有"能不能"（有没有钱、有没有地、政策允不允许）

#### 四、输出要求

报告里应有独立一节「**现实审查**」，逐条列出：结论依赖的主体行为 → 该行为的动机 → 该动机在本结论的价格/利润水平下**是否成立**。
不成立的行为，必须从结论里删掉，并相应修正结论。

### P9 推算数据必须有现实支撑 —— 不许凭空想象

> 这是统领全树的第一硬规则。**P1–P8 管"怎么想"，P9 管"每个数字从哪来"**——一个算式再漂亮，只要里面的数答不出出处，整份报告就作废。

**任何进入报告的"推算值"（预测价格、预测利润、预测产能、折现率、以及各种系数与折算率），都必须能当场回答两件事：**

1. **它对应的现实是什么？**（谁的行为、什么机制、哪条硬约束产生出来的）
2. **支撑它的信息是什么？**（哪份一手披露 / 官方统计 / 可反算的恒等关系）

**答不上来的 → 这个数字就是"拍脑袋"出来的，不许出现在报告里。**

#### 一、什么是"凭空想象"（最常见的四种伪装）

| 伪装形式 | 为什么它是凭空想象 | 正确做法 |
|---|---|---|
| **拍脑袋的系数 / 折算率** | 为了让算式"对得上"，硬塞一个比例（例：`归母 = 单位净利 × 销量 × 0.68`，那个 0.68 没有任何出处） | **把折算率拆开**：它到底代表所得税？少数股东损益？期间费用？——**逐项查实**；能一步算出的就不设折算 |
| **凭感觉的折现率 / 增速** | "折现率取 X%""给 5% 增长"，说不出锚在哪 | 用**可观测值锚定**：无风险利率 + 风险溢价；或直接引用公司披露 |
| **单点外推** | 用一年数据、一个斜率就推未来 | 至少要有**一条完整周期**或**一个机制解释**（见 P3、P5） |
| **拿"行业平均"顶替公司实际** | 公司自己披露了，却去用二手汇编 | 一手优先（见 P5 取数顺序） |

#### 二、三条硬规则

1. **每个推算值都要能溯源**：正文里每个预测数字旁，标出「依据 + 时点」。标不出的，**删掉**；确实只是假设的，**降级为"情景假设"并明确写出**。
2. **能从现实直接算的，绝不多加一层**：能一步算出的（例：`（价格 − 完全成本）× 数量`），就**不引入任何中间比例**。**中间环节每多一层，就多一层凭空想象的机会**——中间层是重灾区。
3. **假设必须显式化、并接受检验**：确实是假设的（例："行业产能收缩 −10%"），必须写明"**这是一个假设、依据是什么、若不成立结论怎么变**"，**不能伪装成"算出来的事实"**。

#### 三、交付前自问（与 P8 并列的收口动作）

> 报告里每一个数字，**如果被追问"你这个数哪来的"，我能立刻答出"来自哪份文件 / 哪个机制 / 哪条恒等关系"吗？**
> **只要有一个答不出——它就是想象出来的，必须删掉重来。**

**一句话**：**能溯源的是数据，不能溯源的是幻想；报告里只准放前者。**
