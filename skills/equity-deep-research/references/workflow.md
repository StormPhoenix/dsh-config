## S1 节点是什么

**每个节点必须是一个待回答的命题**，能回答"是 / 否"或"多少"。
反例：`收入 = 量 × 价`、`量` —— 这是公式和概念，不是命题。正例：`利润会如何变化`、`主要产品的合理价格是多少`。

数据不是节点，数据贴在节点上。每个节点记录四项：

```
命题 | 数据（值 + 时点 + 来源）| 当前判断 | 状态（生长中 / 已收工 / 已剪枝）
```

缺数据时，第四项标为"数据缺口"——留痕，不留空。

## S2 初始问题与三分叉

**初始问题 = 三个分叉**，**直接落位，不推导**：

1. **当前状态下的合理价值** —— 不增长也值多少
2. **预期未来的合理价值** —— 增长兑现后值多少
3. **是否存在炒作价值** —— 短期资金愿意给多少

这三点是"价值"这个词本身的三副面孔。**MECE 从这三块的下一层才开始用。**

## S3 每层动作序列 —— 切 → 排 → 挖

| 步骤 | 做什么 |
|---|---|
| **① 切**（横向 MECE） | 选一个维度，把节点切成互斥穷尽的**组成部分**；同层只用一个维度。检验：子命题全真 ⟺ 父命题真 |
| **② 排**（定优先级） | 对刚切出的**并列**子节点按**影响力**排序——谁变一档，父命题动得最多 |
| **③ 挖**（纵向） | **只对影响力最高的那一支**追问"由什么决定""现在处在什么状态"；其余节点降为参数，先放着 |

**切之前先回报**：恒等式（`利润 = 收入 − 成本 − 一税三费`、`收入 = 销量 × 单价`）是定义、不是命题，**不占层**。切之前先让子 agent 回报"公司性质 + 利润实际由哪些变量驱动 + 哪些项不适用"，主 agent 据此**直接切到可调研的驱动**，并**砍掉不适用项**（如免税行业无"税"、价格与成本强联动时合并成"价差"）。把恒等拆解单列一层，等于让子 agent 去查一个不需要调研的定义。

**推导链也不占层**：`价格 = f(供给, 需求)`、`供给过剩 = f(产能, 需求)` 是"结论 → 原因"的推导，不是层级；节点必须是**可查的事实**（产能、库存、消费、份额……），不用"由什么决定"这种元问题占位。两条切法：
- **需求归价格支，销量只查公司自身** —— 需求是行业大数、由大环境决定，作用是改变供需平衡，是价格的输入，故放在**价格支**；上市公司销量不随大环境需求同比例变动（总需求下滑先冲击低质产品的销量），故销量支只查**公司自身的份额 / 竞争力**。同一维度只查一次。
- **供需对比不占层** —— "供给会不会过剩"不是节点，它是"**供给侧趋势 − 需求侧趋势**"的**结论**，在趋势差一步算出，不进树。

**派发口径只写"怎么查"**：命题后的 `→` 只描述子 agent 的**调研方法 / 口径**（查什么性质、走哪条取数路径），**不得把下一层已穷举的子命题当例子罗列**——那些子命题本身就是下一层的节点，重复列举等于把答案写进问题。

**铁律：每做一次 MECE 切开，就立刻排一次优先级；纵向思考永远优先给影响力最高的那一支。**

- 把 MECE 拆出的并列节点**平均用力**，那不是分析，是列清单
- 排不出高下时用敏感度算（单位变动 → 结论变化多少）；仍排不出，说明这一刀切得没有区分度，考虑换维度
- 被排到后面的节点不是不重要，而是**在当前层不决定结论**——它们随时可在下一轮被重新提上来

**为什么必须这样**：答案通常由一个变量决定。若把精力平摊，最高权重的变量只能分到一小部分深度，结论必然浮在表面。

后续层重复同一序列：挖出的原因构成新的"整体"，再切、再排、再挖。

举例：

- 对 `利润会如何变化` **切** → `价格 / 销量 / 成本 / 费用`（直接切到可调研的驱动，跳过 `收入 = 量 × 价` 这层恒等拆解）
- **排**：价格影响力最大（价直接决定利润主体）
- **挖**价格 → `产能在怎么变化 / 库存【非大宗商品不考虑】/ 进口量【不可贸易品不考虑】/ 替代品【独家不考虑】/ 需求（刚需看人口、非刚需看意愿）`（价格支只挂事实：供给端 + 需求端；`【】`= 该行业不适用、直接砍掉）
- 对 `销量` 再 **切 → 排 → 挖** → `份额在怎么变`（销量支只查公司自身，不重复查需求）

## S4 回溯验证（保证没切错）

切完之后，把子命题全部回答，再回到父命题：**能不能回答？**

- 能 → 这一刀切对了
- 不能 → **切错了维度，退回重切**（而不是硬往下钻）

这一步是 MECE 正确性的唯一检验，每层都要做。

## S5 两个锚

- **供需锚 —— 管"原因类"节点**：凡是问"为什么 / 由什么决定"的节点，都要能归到**供给**或**需求**的一侧。归不了，说明这一刀切错。
- **利润锚 —— 管"结果类"节点**：所有分支的终点都要能连回**利润**。连不回，剪掉。
  （估值、回本年限、折现这类**定价节点**天生不属于供需，只要确认它由利润驱动即可。）

## S6 异常优先

S3 的「排」是按**影响力**排序。此外还有一条独立规则：

**取数时若撞上异常值（与预期背离），立刻优先深化那一支**——异常通常就是预期差所在，它的信息量高于按常规排序应得的位置。

其余情况一律按 S3 的影响力排序走。

## S7 深度要求

**最深路径 ≥ 6 层**——是"最深路径"，不是每条支都要 6 层。可操作的分支允许提前收工。

## S8 终止条件（两级，不要混淆）

**A. 分支级 —— 一条线何时停止生长**（满足任一即停）

- 触底：再也问不出"由什么决定"
- 触数据边界：公开渠道确实拿不到 → 剪掉，记为数据缺口
- 判定无关：连不回利润 → 剪掉
- 已可操作：该支已能给出量化判断，无须再细分

**B. 整体级 —— 整棵树何时收工**（须同时满足）

- 所有叶子已落地（有数据）或已明确标为缺口
- 最深路径 ≥ 6 层
- 初始问题（三分叉）已能回答：三块都有可量化的结论
- 再长一层不再改变结论（边际信息量低于其成本）

**关键区别**：分支终止 ≠ 整体终止。剪掉一支只说明这一刀到此为止，树要继续在其余节点上长。反过来，某支还能挖也不代表整体没到收工点——已判定不改变主结论的分支，标低优先级即可。

## S9 验收标准

- 最深路径 ≥ 6 层
- 每个节点都是命题，且带数据（值 + 时点 + 来源）或明确标缺口
- 每条叶子都能连回利润
- 至少有一条分支是**由异常数据**长出来的
- 三个分叉都有量化结论
