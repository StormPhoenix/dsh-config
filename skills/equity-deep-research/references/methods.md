## 四口径交叉 ——「利润会如何变化」

同一年利润，四个口径各算一遍，给区间，主口径取居中偏保守：

| 口径 | 含义 |
|---|---|
| 归母净利 | 会计利润，最常用、偏乐观 |
| 扣非归母 | 剔除一次性损益 |
| 经营现金流 | 收现能力 |
| 股东实收分红 | 真正落到股东口袋 |

---

## 回本年限法 ——「估值合不合理」

```
零增长：  N = 市值 ÷ 年利润
固定增速：解 Σ(t=1..N) P0 × (1+g)^(t-1) = 市值
简单年化 = 100% ÷ N
复利年化 = 2^(1/N) − 1
```

门槛回报 R = **9.6%**（本 skill 统一标准，全文只用这一个；推导口径：无风险利率 + 风险溢价；不得改用 10%、12%）：

```
复利口径：需 N ≤ ln2 / ln(1+R)
简单口径：需 N ≤ 1/R
合理价 = 该 N 上限对应的累计利润 ÷ 总股本
偏低估 = 合理价 × 0.85        低估 = 合理价 × 0.70
```

买价两口径：市值；企业价值 EV = 市值 − 净现金（货币资金 + 交易性金融资产 − 有息负债）。

## 增速桥 ——「增长从哪来」

```
利润增速 ≈ 存量收入增速 + 增量业务贡献 + 净利率变化贡献
```

存量收入拆"量 × 价"；增量业务按兑现节奏给假设（区分"并表基数效应"与"自身放量"）；净利率变化由费用率、结构、上游成本决定。每段给区间再合成。

---

## 可持续增长率 ——「增长能持续多久」

```
g = ROE × 留存率 = ROE × (1 − 分红率)
```

假设增速高于 g 时，必须说明增量从哪来（ROE 继续升 / 降分红 / 外延），否则不自洽。历史高增速若来自 ROE 的一次性修复，不可外推。

---

## 三情景加权 ——「未来值多少」

```
CAGR = (期末值 ÷ 基期值)^(1/年数) − 1
中枢 = Σ(情景 CAGR × 概率)
```

与卖方一致预期对照时，先指出其隐含假设（如"要实现该预测，下半年需同比 +X%"）再判断是否合理。

---

## 概率加权期望排序 ——「哪个因子最要紧」

排序键 = 方向 × 幅度 × 概率，**不按最大幅度**。每因子给：方向、幅度、概率、期望、性质（一次性 / 持续 / 已兑现）。

---

## 利润折现 —— 下限校验

```
折现率 = 门槛回报 R
显式期 5~10 年 + 终值（永续 0 增长 / 低速增长两档）
反向用法：由当前市值反算隐含增速，看市场已定价多少增长
```

---

## 压力测试 ——「会不会衰退」

设定冲击（主打产品降价 X%、商誉全额减值、份额流失 Y%）→ 算对净利的绝对影响与占比 → 给概率 → 找出决定"温和侵蚀"还是"实质重创"的**开关变量**。

---

## 交叉验证 ——「结论可靠吗」

同一结论用四种方法各算一遍，说明差异来自哪个假设，**取最保守者为主结论**：
回本年限（最保守）→ 可持续增长率（内生天花板）→ 三情景加权（中枢）→ 利润折现含终值（最宽松）。
