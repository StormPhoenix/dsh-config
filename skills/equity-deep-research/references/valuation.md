## 量化纪律

- 全部量化；无法精确的给区间
- 每层结论用数字表述，不用"较好""有望"
- 关键节点多口径交叉验证，取最保守者
- 概率须锚定可查证事实

## 硬规则：一切预测必须自算

**利润、价格、销量、增速、目标价，全部自己从供需与产能推演，不得采用卖方预测作为结论或测算输入。**

- 自算路径：从产能推供给 → 从需求侧推需求 → 合成价格 → 从成本结构推成本 → 利润 =（价格 − 成本）× 数量
- 卖方（券商）的盈利预测与目标价**只能作为"市场预期"的参照物**，用途仅有一个：判断当前价格已经定价了什么
- 引用卖方数据时必须写"**市场预期，不采用**"；不得让卖方数字进入任何测算链条
- 若自算结果与卖方显著不同，保留自算结果，并把差异本身当作预期差的线索

## 硬规则：估值口径必须钉死（否则同一只股票两次跑出两个答案）

**症状**：同一只股票、同一套 skill，不同 agent 跑出相差一倍的合理价。根因不是"判断不同"，而是**关键假设没钉死**，各人各取一套。以下七项必须写死：

1. **售价口径 —— 用公司自己的实际售价，且与行业价"同口径"比较**。
   - 常态利润里的"价格"，取自**公司披露的实际销售均价**（月度经营数据 / 年报 / 业绩预告），这是**一手**数据（P5 取数顺序：公司披露 ＞ 官方统计 ＞ 第三方）。**不得把行业均价直接当公司售价**。
   - 若要用"行业价 − 价差"折出公司价，**价差必须用同一口径的行业序列来测**：公司价对应的是**出厂 / 批发口径**，就必须拿**同口径的行业价格序列**去比，**不得拿含下游环节溢价的零售 / 集贸价去比**——那会**凭空造出一个假价差**，把公司售价系统性压低。
     - （示例：生猪公司卖的是"出栏价"，须用"外三元 / 瘦肉型出栏价"比，不得用"活猪集贸价"；钢铁公司卖的是"出厂价"，不得用"建材市场零售价"。）
   - 价差要**逐年、多期列出**，取**最近期或中位数**，**不得只用一年**。
   - **口径差只能扣一次，且"中枢"与"成本"必须同源**：若价格中枢取自甲口径（如零售 / 集贸口径），而成本取自乙口径（如生产 / 完全成本口径），**必须先把两者换算到同一口径再相减**。**禁止**"中枢按甲口径定、再对公司价扣一次口径差"的**双重扣减**——它会凭空再造一次假价差，把公司售价压到"洗牌价"水平。
2. **残差必须拆开 —— 不许用一个"价差"吸收一切**（P9 硬规则的落地）。
   - "行业价 − 公司价"这个残差里混着**口径差（出厂 vs 零售）、产品结构差（规格 / 等级 / 品种）、期间费用、少数股东、非经常项**。**必须逐项拆开、各自给出处**；拆不开的标为"情景假设"。
   - **禁止**把上述几项打成一个"X 元 / 单位价差"再乘回去——那正是 P9 说的"拍脑袋折算率"。**残差 > 公司售价 5% 且拆不开 → 不许使用该模型。**
   - **公司售价与单位规格必须用恒等关系自算并互相反查**：`公司售价 = 主营收入 ÷ 销量 ÷ 单位规格`；公司同时披露金额、量与价时，`单位规格 = 金额 ÷ 量 ÷ 价`。三者必须自洽，不得用行业均值顶替。
     - （示例：生猪 `售价 = 商品猪销售额 ÷ 出栏量 ÷ 出栏均重`；水泥 `售价 = 销售收入 ÷ 销量 ÷ 单吨口径`。）
3. **常态中枢 = "微利"水平，不是"保本 / 洗牌"水平**（P4 的强制落地）。
   - 中枢必须锚定到**实证的"全行业微利"状态**——找官方 / 权威口径明确说"行业整体微利 / 单位盈利仅 X 元"的那段时间，用**当时的价格**当中枢；**不得用"行业平均完全成本"（保本线）当中枢**。
   - 用保本线当中枢，等于假设半数主体长期不赚钱——这是"洗牌价当中枢"的变种，**系统性低估**。
   - 找不到微利锚时，用 **中枢 = 保本线 + 微利溢价**，且**溢价量级必须给出依据**（取历史上"行业整体微利"年的**单位盈利 ÷ 单位量**，折成元 / 单位），不得随手给数。
   - **中枢必须过 P4 产出形态检验**：把中枢价套进成本分布，若结果是"半数以上主体 / 产出亏损"，**该值就是洗牌价，必须上修到"多数产出微利"的水平**，再当常态中枢。
   - 常态年锚**只能取常态 / 微利年**；**高位年、亏损年、含大额一次性项的年**一律不得当"常态锚"。
4. **成本口径 —— 按 P3 外推，但外推必须由「已兑现的事实」支撑**（与 G4 对称验证一致）。
   - 常态成本 = **最近实际值 − 可确认的降本幅度**，且该降本幅度**必须有已发生的证据**：公司**已兑现**的降本历史、已投产降本载体的**实测值**、同业同规模的降本斜率。
     - （示例：新产线 / 新基地的**满产率实测值**、一体化投产后的单位成本实测值。）
   - **公司目标 / 管理层指引不得直接当降本依据**：允许入账，但必须按公司自身**历史兑现率打折**并标"打折后"；**无历史可依 → 视为"情景假设"，不得进常态口径**（G4）。
   - 设**下限 = 现金成本**。取"最新值"当常态成本，等于假设降本趋势立刻停止，与 P3 矛盾；用未兑现的目标当依据，则是 G4 说的方向性偏置——两头都不许。
5. **分叉二的方法 —— 二选一写死，并标明它回答的是哪个问题**：
   - **路径求和法（周期股默认用这支）**：先列出上行路径的**逐年利润**（反转年 + 高位年），再**以「高位年」的年均可分配利润作为估值锚**——**反转年是从底部爬升的过渡年，把它平均进去会把高位价值稀释回常态**（这正是分叉二退化为分叉一复读的主因）；合理价 = 高位年平均利润 × 回本年限 ÷ 股本。它回答"若反转兑现、进入高位，值多少"。
     - **同时给出「含反转年的保守下界」**（即把反转年也平均进去）供对照；两个数都要写进结论框，主结论取高位年口径。
     - **高位价格必须由「供给收缩深度 → 历史对应高位」自算**（不许直接抄历史高点，也不许只取单一年份）；高位年数取历史正常周期的众数（通常 2 年），并写明依据。
   - **期望值法**：给情景概率、加权得期望利润 → 回答"按概率，平均值多少"。**概率必须锚定历史基率**（历史上同等供给收缩深度 → 出现高位的频次），**不得凭感觉给 35%/45%/20%**。
   - 两者**不得混用**；用了哪个，结论框里必须写明。
   - **反复读校验**：算完必须比一比分叉二与分叉一。**若两者相差在 ±20% 以内，即触发 P6「分叉二沦为分叉一复读」告警**——多半是"用期望值法、概率把反转稀释回了常态"，或"把反转当成了回到中枢"。此时**必须改用路径求和法**（或回查链条），不得就此交付。
6. **门槛回报全文统一为 9.6%**：本 skill 固定门槛 **R = 9.6%**（推导口径：无风险利率 + 风险溢价）；**全文只用这一个值**，不得出现 10%、12% 等其他门槛；计算器 `scripts/repay_period.py` 默认即为 0.096。
7. **量 / 单位规格口径必须与价格同源**：销量用**公司披露口径**，单位规格取**公司自算值**（金额 ÷ 量 ÷ 价），**不得用行业均值顶替**。同一份报告里，**量、价、规格三者必须来自同一口径**，否则反算必然对不上。

**反算校验（本条的强制收口）**：常态口径必须能**反算回最近一个"微利年"的实际归母**，误差 >10% 即为口径错配（P7 反算核验）。

- **必须用"微利年"反算，不得用"亏损年 / 洗牌年"反算**：用亏损年反算，会把常态口径钉死在"洗牌"状态，系统性低估（P4）。
- **反算通过 ≠ 口径正确**：若"通过"是靠塞进一个**无出处的残差**凑出来的，**不算通过**（G2）——必须先把该残差拆开、给出处（见第 2 条），拆不开就不许用。

**验收**：同一只股票、同一套口径跑两遍，结论必须落在同一区间；落在不同区间即为口径未钉死。

## 硬规则：政策与规则必须读原文

- **必须读原文**：涉及政策、法规、监管口径时，一律查**原文**，不依赖媒体转述或二手摘要——转述最常见的失真就是把**区间简化成点值**、把"**左右**"省略掉。
- **先问它是点值还是区间**：政策目标常是区间或含糊量。引用前必须确认区间上下限。
  - （示例：生猪调控目标"能繁母猪正常保有量稳定在 3,750 万头**左右**"，原文划定了绿 / 黄 / 红三个**区间**。）
- **区分"目标"与"结果"**：政策说"调控到某水平"**不等于**会调控到该水平，更不等于会实现。目标是意图，结果由市场决定。
  - **绝不可把政策目标当作预测输入**——"距目标仅差 X% → 达标即反转"是错误推理。
  - 政策只用于判断两件事：**政策会在什么条件下出手**、**朝哪个方向用力**。
- **必须自己推平衡点**：政策目标之外，用供需与效率自己算"真正的平衡点"，它常常与政策目标不一致。
